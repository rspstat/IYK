### MBTI 여행 DNA — 충청북도 맞춤형 관광정보 추천 및 여행 커뮤니티 서비스

## 서비스 개요

MBTI 16개 유형을 기반으로 **충청북도** 여행지를 추천하는 웹 서비스입니다.  
한국관광공사 OpenAPI 데이터를 활용하여 충청북도 관광지 정보, 사진, 혼잡도 예측 기능을 제공하며,  
인스타그램 형식의 피드 UI와 SNS 기능(좋아요·댓글·공유)을 통해 여행 경험을 공유할 수 있습니다.

## 페이지별 상세 설명

### ① 메인 페이지
- MBTI 16개 유형(INTJ, INTP, ... ESFP)을 버튼 그리드 형태로 표시
- 유형 선택 시 충청북도 기반 결과 페이지로 이동

### ② 결과 페이지
- **여행 스타일 카드**: 선택한 MBTI 유형의 여행 성향, 태그, 추천 팁 표시
- **추천 명소 리스트**: MBTI 유형별로 사전 매핑된 특화 API(반려동물·무장애·웰니스·캠핑·두루누비 등)를 내부적으로 조합하여 성향에 맞는 충청북도 관광지를 사진·이름·지역 정보 및 혼잡도 예측 뱃지와 함께 리스트로 제공
  - 예) ESTP → 레포츠·액티비티 중심 관광지 / INFJ → 웰니스·자연 힐링 관광지

### ③ 상세 페이지
- 명소 클릭 또는 "자세히 보기" 버튼으로 진입
- **사진 갤러리**: 관광사진 API + 공모전 수상 사진, 슬라이드 형식
- **관광지 정보**: 소개·위치·운영시간 (국문 관광정보 API)
- **혼잡도 캘린더**: 향후 30일 방문자 집중률 예측 히트맵 및 추천 방문일 제안
- **연관 관광지**: "이런 곳도 가보세요" 자동 추천
- **여행 경로 정하기**: 버튼 클릭 시 여행 경로 페이지로 이동

### ④ 여행 경로 페이지
- 상세 페이지 내 "여행 경로 정하기" 버튼 클릭 시 이동
- 연관 관광지들을 포함한 충청북도 여행 경로 페이지로 전환
- 카카오 지도 API를 통해 지도 렌더링 및 추천 관광지 핀 표시
- 방문 순서에 따라 경로를 시각적으로 연결하여 한눈에 동선 파악 가능

### ⑤ SNS 기능
- **좋아요**: 관광지 찜 저장 및 인기 명소 집계
- **댓글**: 여행 후기 텍스트 작성 및 공유
- **공유**: 외부 SNS(카카오톡, 인스타그램 등) 공유

## 지역 특화 — 충청북도

본 서비스는 충청북도를 주요 서비스 대상 지역으로 선정했습니다.  
한국관광공사 API에서 제공되는 관광 데이터를 충북 지역으로 필터링하고, 충북 내 주요 권역의 관광지를 MBTI 유형별 성향과 매핑하여 단순 나열이 아닌 성향 기반의 큐레이션 방식으로 충북 관광지를 소개합니다.  
카카오 지도 API를 통한 여행 경로 시각화 기능에서도 충북 내 동선을 중심으로 경로를 구성하여, 사용자가 충청북도를 실질적으로 탐색하고 여행 계획을 수립할 수 있도록 서비스 전반에 지역 특화 요소를 반영하였습니다.

<br/>

## MBTI × API 매핑 방식

사용자가 MBTI 유형을 선택하면 별도의 필터 조작 없이, 유형별로 사전 정의된 특화 API 조합이 내부적으로 자동 호출됩니다.

| MBTI 성향 분류 | 활용 특화 API | 예시 유형 |
|--------------|-------------|---------|
| 액티비티·레저 중심 | 두루누비, 국문관광정보(레포츠) | ESTP, ISTP, ENTP |
| 힐링·웰니스 중심 | 웰니스관광정보 | INFJ, INFP, ISFJ |
| 자연·캠핑 중심 | 고캠핑, 두루누비 | INTP, ISTJ, ISFP |
| 동반·가족 중심 | 반려동물 동반여행, 무장애 여행 | ESFJ, ENFJ, ISFJ |
| 문화·역사 중심 | 국문관광정보(문화시설·관광지) | INTJ, ENFP, ESTJ |
